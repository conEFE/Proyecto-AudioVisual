# Logos

`logo-aurora.png` es el logo oficial (1024 × 1024 px, PNG con fondo `brand-night` incluido). Viene del repositorio en `src/assets/logo-aurora.png` y se usa en la vista Inicio a 224px de alto.

- Úsalo solo sobre `brand-night` o `background`: el fondo del archivo no es transparente.
- No hay versión en una sola tinta, ni horizontal, ni solo el símbolo. Si hace falta alguna, hay que diseñarla aparte.
- No hay versión vectorial (SVG): para impresión grande se necesita rehacerlo en vector.
